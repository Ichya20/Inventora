# Motion Inventora

28 Oktober 2026

## Pembuka logo

Pembuka memakai dua bidang: logo besar pada latar arang di kiri, lalu nama Inventora, satu keterangan, dan tombol masuk pada bidang putih di kanan. Pada ponsel, logo berada di atas konten. Warna logo memakai versi terang yang sudah digunakan pada tema gelap. Plus Jakarta Sans dipertahankan; tidak ada slogan tambahan, persentase loading, atau ornamen latar.

Logo pembuka memakai data Lottie khusus melalui `@lottiefiles/dotlottie-react`. Empat kotak bergerak sedikit keluar dengan kemiringan paling besar 4 derajat, lalu kembali ke susunan awal. Data berisi 72 frame pada 60 fps, diputar pada kecepatan 0,5 sehingga pembuka berlangsung 2,4 detik tanpa mengulang intro. Frame awal dan akhir identik. Setelah selesai, logo bergerak naik-turun paling jauh 5 px dengan perubahan skala 1,2% dalam siklus idle enam detik. Idle memakai transform CSS; timeline canvas sudah selesai. Geometri asli dipertahankan: viewBox SVG 24 × 24, empat persegi 8 × 8 pada koordinat 2/14, radius 1,5, dan dua kotak beropasitas 15%; data Lottie memakai skala sepuluh kali ukuran itu.

Player dan WASM dimuat secara terpisah hanya saat animasi dibutuhkan. File WASM disertakan dalam hasil build dan dimuat dari origin aplikasi. SVG asli tetap terlihat sampai player siap, serta menjadi cadangan jika modul atau renderer gagal. Tidak ada pengambilan aset animasi dari CDN. Loading aplikasi tetap memakai `InventoraBrand` versi 64 px dan indikator yang mengikuti pemuatan sebenarnya.

Animasi pembuka otomatis berjalan setiap halaman `/` dibuka, termasuk kunjungan ulang. Penanda sesi dan kontrol replay dihapus. Tombol masuk langsung terlihat dan dapat digunakan selama animasi berlangsung. Ikon kecil pada bidang logo dapat menjeda dan melanjutkan intro atau idle tanpa mengulang intro yang sudah selesai. Label aksesibelnya mengikuti bahasa aplikasi. Tidak ada listener Enter global yang mengambil alih kontrol bahasa atau tombol lain. Bila sistem meminta reduced motion, player logo tidak dimuat, idle dinonaktifkan, konten langsung ditampilkan tanpa gerakan, indikator loading berhenti berputar, dan kontrol animasi disembunyikan.

Konsep mengikuti arah **The split stage**, seed 1437071693, dengan palet dan font merek dipertahankan. Saran foto dan susunan beberapa bagian tidak diterapkan karena halaman ini hanya pembuka aplikasi. Pencarian katalog 21st memerlukan login; komponen project tetap digunakan. Dokumentasi reduced motion dibaca melalui MCP Motion yang sudah terhubung.

## Ruang kerja

- Halaman masuk menggunakan fade dan pergeseran 5 px selama 200 ms. Animasi tidak mempertahankan transform setelah selesai.
- Modal masuk selama 180 ms, drawer 240 ms, dan keluar 140 ms. Modal pada layar sampai 767 px menggunakan susunan bottom sheet, dengan footer yang memperhitungkan safe area. Native dialog dan pengelolaan fokus browser dipertahankan.
- Baris baru pada PO diberi sorotan sementara. Perubahan subtotal dan status memakai lapisan sorotan yang tidak membongkar input. Daftar barang tidak menggunakan animasi pergeseran layout.
- Status PO dari Firestore yang masih memiliki pending writes tidak menggantikan status terkonfirmasi. Sorotan mengikuti perubahan data yang diterima oleh tampilan.
- Produk baru pada keranjang POS masuk selama 160 ms; penghapusan memakai fade singkat. Perubahan jumlah, harga, diskon, subtotal barang, dan total diberi feedback tanpa menghitung nominal dari nol.
- Centang sukses pada struk POS tampil setelah checkout selesai menyimpan. Membuka struk lama tidak memutar ulang konfirmasi transaksi baru. Kegagalan checkout mempertahankan perilaku error sebelumnya.
- Grafik analitik dan distribusi PO memakai durasi 380 ms. Data grafik analitik dipertahankan antar-render agar mengetik di asisten tidak mengulang animasinya.
- Skeleton memiliki susunan tabel, form, dan POS. Digunakan saat modul/data benar-benar dimuat. Jeda loading buatan pada login demo dihapus.
- MotionConfig, hook reduced motion, dan aturan CSS reduced motion tetap diterapkan. Tidak ada suara baru atau animasi dekoratif berulang.

Komponen terkait: `OpeningSequence`, `InventoraLogoAnimation`, `InventoraLogoPlayer`, `InventoraBrand`, `InventoraMark`, `MotionFeedback`, `UI`, `PosView`, `PurchaseUnitView`, `ProcurementView`, `PurchaseOrderDrawer`, `ProcurementOverview`, `AnalyticsView`, `ViewSkeleton`, dan `InventoraLoadingScreen`. Data logo Lottie tersimpan pada `src/lib/inventoraLogo.ts`. Durasi serta easing antarmuka Motion disimpan pada `src/lib/motion.ts`.

## Video pendamping

`output/motion/inventora-motion-demo.mp4` adalah ilustrasi alur dengan data contoh: pembuka logo, inventori, persetujuan PO, penerimaan, dan POS. Durasi 26 detik, 1280 × 720, 24 fps, H.264 tanpa audio. Video dibuat sebelum revisi splash terbaru dan bukan rekaman browser. POS dijelaskan sebagai penyimpanan lokal; scene pengadaan dan kasir merupakan contoh terpisah. Tidak ada data pengguna yang diambil untuk video.

Sumber Python yang dapat diedit, storyboard, font berlisensi OFL, serta kredit tersedia pada `output/motion/`. Kredit pola transisi: **24fps.dev/video-editor**, https://24fps.dev/video-editor/transitions/slide-over-left-cat1 dan https://24fps.dev/video-editor/transitions/slide-over-up-cat1. Referensi katalog video: **@pbteja1998**, https://24fps.dev/c/saas-product-launch-video-00249 dan **@notdwd**, https://24fps.dev/c/brand-rebuild-product-sting-with-html-canvas-and-playwright-02758. Tidak ada klip atau kode pihak ketiga dari contoh tersebut yang disalin.

## Verifikasi dan batas pemeriksaan

- 80 pengujian aplikasi lulus setelah perubahan terakhir, termasuk perhitungan POS, kegagalan penyimpanan, idempotensi, perizinan, pembuatan PO, dan penerimaan.
- TypeScript (`npm run lint`) dan build produksi (`npm run build`) lulus. Peringatan bundle lama di atas 500 kB masih ada.
- Render server memeriksa geometri logo, satu nama merek, penghapusan ornamen lama, loading ringkas bersama dalam dua bahasa, keadaan kunjungan awal/berulang, tautan login yang langsung tersedia, skeleton bilingual, dan markup native dialog. Audit POS memeriksa katalog, pengungkapan penyimpanan lokal, penolakan role HR, serta data rusak.
- Renderer native dotLottie berhasil memuat WASM lokal dan merender seluruh 72 frame. Pemeriksaan memastikan gerakan terjadi, tidak ada kotak menyentuh tepi kanvas, opasitas diagonal tetap sesuai, dan frame awal/akhir identik. Sampel piksel tersedia pada `output/motion/splash-logo/`. Pemeriksaan ini tidak memakai browser.
- Lint desain pada lima file splash menghasilkan 0 kegagalan dan 0 peringatan.
- Review lokal 21st pada lima file splash baru menghasilkan 0 error, 0 peringatan, dan 16 saran informasional tentang nilai warna. Nilai tersebut mendefinisikan palet monokrom khusus pembuka, sehingga dipertahankan.
- Review lokal 21st sebelum revisi dotLottie pada tujuh file splash menghasilkan 0 error, 0 peringatan, dan 6 saran informasional tentang warna netral pada bayangan. Hasil tersimpan di `output/audit/splash-review-2026-10-28.json`.
- Review lokal 21st pada sembilan file komponen/shared motion menghasilkan 0 error, 2 peringatan lebar tabel, dan 2 saran warna logo. Lebar minimum tabel tetap berada di kontainer scroll; warna khusus logo dipertahankan untuk identitas merek. Pencarian katalog CLI meminta login, sehingga komponen project yang sudah ada digunakan kembali tanpa upload sumber.
- Seluruh 624 frame MP4 berhasil didekode; storyboard ilustrasi diperiksa secara visual.
- Animasi, fokus native dialog, dan tata letak aplikasi langsung di browser belum diverifikasi. Akses browser pada sesi sebelumnya ditolak; tidak digunakan jalur screenshot atau browser alternatif.

Tidak ada perubahan konfigurasi, rules, kredensial, deployment, atau data Firebase. Paket dotLottie yang sebelumnya dipasang kini digunakan pada chunk pembuka yang dimuat terpisah. Runtime pengodean video berada di cache lokal di luar project.

Untuk meninjau pembuka ketika server berjalan, buka `http://localhost:3000/`. Muat ulang halaman untuk melihat intro; setelah 2,4 detik gerakan beralih ke idle. Ikon jeda pada bidang logo menghentikan gerakan.
